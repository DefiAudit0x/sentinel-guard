LOCAL PROTOTYPE · NEAR TESTNET

Testnet transfer preflight

The standard preflight is read-only. A separate fixed 0.001 NEAR self-transfer demonstration can request a wallet transaction only after a local ALLOW, an exact review screen, and a second deliberate click. It is not production security enforcement.

Connecting or requesting a transaction involves an unaudited third-party executor. The application checks one fixed Testnet transfer and does not sign automatically. The Meteor executor has not been audited and may not obey this application's checks. A wallet confirmation is still required; verify the exact transaction there. The preflight result is not a safety guarantee.

01 · WALLET

Connect to testnet

NEAR TESTNET

Not connected. Nothing connects automatically.

Third-party executor risk — review before connecting. Connecting loads Meteor's executor, pinned to commit 6369ad7, through NEAR Connect and requests wallet account sign-in. The manifest grants the executor NEAR Connect storage permission and access to Meteor's meteorCom and meteorComV2 bridges; it may open only https://wallet.meteorwallet.app or https://meteorwallet.app. This demo also declares NEAR Connect's single-transaction sign-and-send feature for a fixed Testnet transfer. The executor is unaudited; this application cannot guarantee that its code is limited to the displayed intent. Connect only if you trust this executor and its permissions.

02 · READ-ONLY CHECK

Check a transfer intent

Recipient is fixed by the local policy.

Enter a positive amount up to 0.1 NEAR. Decimal precision is exact; no floating-point conversion is used. This button only runs the read-only preflight.

Optional risk context

Only enter values you actually know. These caller-supplied values are not independently verified. Leaving them blank may produce NEEDS_REVIEW; they are never invented by the app.

If the local guard returns ALLOW, the read-only preflight sends the selected public account ID to https://rpc.testnet.near.org for a read-only account lookup; WARN or BLOCK stops before that RPC read. The local server's request-supplied account ID is not proof of wallet ownership.

03 · OPTIONAL TESTNET DEMO

Prepare a fixed self-transfer

0.001 NEAR

Fixed intent: sender and receiver are both defiaudit0x.testnet; action is one native NEAR Transfer; amount is 1000000000000000000000 yoctoNEAR. The sender is taken from the connected wallet's live Testnet account list, not from the local server request.

This runs a fresh local guard and read-only account lookup. An ALLOW only opens the review below; it does not call the wallet. The latest balance must cover the transfer amount, but fees are not estimated and the wallet may still reject it.

Connect the exact Testnet sender first. No transfer is prepared automatically.
